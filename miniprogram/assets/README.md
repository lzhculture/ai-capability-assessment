# assets 目录

## qrcode.png — 小程序码（可选，但强烈建议放）

海报底部左下角会画一张小程序码，别人长按海报就能进小程序。

### 为什么不是自动生成的

生成带参数的小程序码（`wxacode.getUnlimited`）是**服务端 API**，要用 `access_token`。
当前工程是零服务端设计，所以改成：你手动下载一张普通小程序码放进这里，`utils/poster.js` 直接画到海报上。

### 怎么拿

1. 进 [微信公众平台](https://mp.weixin.qq.com) → 登录你的小程序账号
2. 左侧「设置」→「基本设置」→ 页面最下方「小程序码」
3. 点「下载」→ 选尺寸 **500px 以上**
4. 把文件重命名成 `qrcode.png`，放到本目录下

### 规格

| 项 | 要求 |
|---|---|
| 文件名 | 必须是 `qrcode.png` |
| 尺寸 | 建议 500×500 以上（海报上画 128px，要保证清晰度） |
| 格式 | PNG，背景白色不透明（海报底色是深蓝渐变，透明码会发灰） |
| 体积 | 建议 < 100 KB |

### 不放会怎样

不会报错。海报会在同一位置画一个**白色圆角占位块 + "小程序码" 文字**，版式完整，可以直接上线，之后再补图也不用改代码——`utils/poster.js` 会自己检测图片能否加载，加载失败自动降级。

### 放图的尺寸换算

海报基准是 750×1080 逻辑像素，底部小程序码区：

- 位置：距左 56px，距底 190px（即 y = 890）
- 边长：128px
- 建议出图按 2 倍图，即二维码实际渲染 256px 左右最清晰
